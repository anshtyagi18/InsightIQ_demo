# Project Brief: AI-Driven Dynamic Analytics Dashboard
*Version: 1.0*
*Created: 2025-01-28*
*Last Updated: 2025-01-28*

## Project Overview
An AI-driven dynamic analytics platform that transforms static dashboards into intelligent, autonomous analytics systems. The platform enables users to upload structured datasets (Excel/CSV) and automatically receive visual dashboards, trends, KPIs, and intelligent business insights generated by autonomous agents.

## Core Problem Statement
Modern dashboards are mostly static and rely on predefined metrics. Businesses struggle to make sense of raw data and manually build charts, detect trends, or extract insights. This creates a significant barrier for teams without deep technical skills or dedicated data science resources.

## Solution Approach
Automate the entire data analysis workflow using AI:
- Automatically interpret structured data uploads
- Generate relevant charts, summaries, and alerts
- Provide natural language Q&A interface for data exploration
- Save time and technical effort for business analysts and decision-makers

## Target Users & Stakeholders

### Primary Users
- **Business Analysts** - Need quick, AI-assisted insights without deep technical skills
- **Project Managers** - Require data-driven decision making tools
- **Operations Teams** - Need automated workflows for data monitoring
- **Startups & SMBs** - Lack data science teams but need intelligence from their data

### User Roles & Personas
- **Data Explorer (Basic)** - Uploads data, views insights/dashboards
- **Analyst (Power User)** - Customizes prompts, workflows, and templates  
- **Admin** - Manages agent configurations, rate limits, model API keys
- **Developer (Optional)** - Integrates AI APIs into other systems

## Core Requirements

### Must-Have Features (MVP)
- Upload structured data (CSV/Excel files)
- Auto-generate dashboards with KPIs, trends, and graphs
- Natural language Q&A interface ("What changed in Q2?")
- Real-time AI agent responses with WebSocket updates
- Backend agent system (Dashboard, Analytics, Workflow agents)
- AI model integration (DeepSeek via OpenRouter)
- Frontend to display insights, charts, and status
- Agent-based backend that parses datasets and generates summaries/visuals
- Upload + preview functionality
- At least one functional agent: **Dashboard Agent** for KPIs & summaries

### Nice-to-Have Features (Future Enhancements)
- Chat-based natural language interface
- Multi-model fallback support (Claude, GPT-4)
- Version control of dashboards
- Scheduling reports or alert triggers
- User authentication and personalization
- Data export and share functionality

## Success Criteria
- Backend response time under 1 second for most requests
- Dashboard updates with near real-time latency (<1.5s) via WebSocket
- AI model inference within 700ms average (DeepSeek acceptable)
- Functional prototype by Week 2
- End-to-end workflow working with real Excel datasets
- MVP ready for testing/competition by Week 3

## Technical Constraints

### Required Technologies
- **Frontend**: React + TypeScript (existing codebase to reuse)
- **Backend**: Python with FastAPI
- **Agent Framework**: LangGraph (preferred hybrid with Google ADK)
- **AI Model Provider**: OpenRouter (DeepSeek for cost efficiency)
- **State Management**: Agent registry + prompt templates
- **Visualization**: Recharts or Plotly.js

### Technology Restrictions
- Must work on limited resources/local dev setups
- Use only one AI model (DeepSeek) initially for free-tier compatibility
- Avoid expensive GPU-based services
- No heavyweight AI infrastructure (local LLM hosting)
- Avoid vendor lock-in solutions (no OpenAI-only dependencies)
- No full-stack no-code platforms (insufficient agent control flexibility)

### Performance Requirements
- Backend API response: <1 second
- Real-time dashboard updates: <1.5 seconds latency
- AI inference: <700ms average response time
- Support concurrent users with rate limiting

### Security Requirements
- API key/token management for AI providers
- Environment-based configuration isolation (.env)
- Optional Bearer-token authentication (already implemented)
- File upload sanitization (CSV/Excel validation)
- Rate limiting for abuse prevention

## Scope

### In Scope

- Agent-based backend architecture
- Real-time dashboard generation
- Natural language data querying
- File upload and processing pipeline
- Integration with DeepSeek via OpenRouter

### Out of Scope (Phase 1)
